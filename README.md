### ♟️☕ Qehwa Chess — a platform for chess in Morocco

A full web app for players, clubs, and tournament organizers — not just a board, a whole community.

- **Discover:** tournaments, clubs, meetups, and players, with events on a map
- **Play & meet:** QR check-in, messaging, and player / organizer / admin dashboards
- **Built for Morocco:** available in English, French, and Arabic

**Stack:** React · TypeScript · Vite · Tailwind CSS · Supabase · Leaflet · QR Code

> This is my main project right now — it's where I put together frontend, backend, auth, maps, and real user roles.
